# Bookshop & Education Learning System

A desktop application built with **Java** and **JavaFX** featuring user and administrator management for an online bookshop and educational learning portal.

## 📖 Features

- **User & Admin Authentication**: Separate registration and sign-in portals for standard users and administrators.
- **Book Catalog & Management**:
  - View available books with descriptions and pricing.
  - Search and filter inventory.
  - Admin controls to add and manage books.
- **Order Placement**: Place and process book orders with real-time text-based record-keeping.
- **Interactive Tools**: Built-in utility features including a calculator, prayer schedule display, and multi-topic review sections.
- **Custom JavaFX UI**: Styled GUI built with FXML and custom graphical assets.

---

## 🛠️ Tech Stack

- **Language:** Java (JDK 8 / JDK 11+)
- **GUI Framework:** JavaFX (FXML)
- **IDE / Build Tool:** NetBeans / Apache Ant
